Just now, we mentioned the resolution matters a lot to the performance of visual language models. How do we deal with very high-resolution images, like 800 by 1300? The internal VLM can support dynamic high resolution using tiling plus thumbnail. Tiling basically says we have several templates to define aspect ratios, like 1x2, 1x3, etc., and we try to match this new image with several templates. We find 2x3 is probably the best match, so we convert it into a 2x3 image, which is closest—896 by 1344. Then we can chop it into six (2x3) different parts, each one 448 by 448 tile, and finally we have a thumbnail, which is a smaller version, downsampled to 448 by 448. We have all them together. Now, one image becomes multiple images, and we can process them one by one, concatenate the tokens.

Interestingly, we find different benchmarks have different results. For text and OCR benchmarks, high resolution helps a lot; as we increase the number of patches (tiles), the accuracy is pretty high. But some tasks, like knowledge and reasoning benchmarks, six tiles is sufficient; if you have more tiles, the accuracy actually drops. So, not necessarily the more tiles, the better—it depends on the task. For text and OCR tasks, high resolution is very helpful, but for knowledge and reasoning tasks, roughly six tiles is the peak.

Another way to support high-resolution image processing is using this cross-attention method in the CogAgent paper. Cross-attention basically says you have low-resolution image features and text features as query, and use the high-resolution image features as key and value, and use cross-attention to process them together. Notice there is a low-resolution image encoder and a high-resolution image encoder. This is probably an image from booking.com: a low-resolution version, a high-resolution version. The high-resolution version is injected with the visual and language decoder using cross-attention, while the low-resolution image encoder's output token is concatenated with the text token, word embedding, MLP adapter. So, low-resolution image feature is concatenated with the text feature, concatenated and fed to the visual language decoder, while the high-resolution image feature is injected through cross-attention.
